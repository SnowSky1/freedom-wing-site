# 自由之翼 · Freedom Wing

以工业设计作品集版式、真实三维模型和滚动变形介绍自由之翼的单页产品网站。模型、材质、动画和图鉴均随项目保存在本地，运行不依赖外部 CDN。

2026-10-14 根据用户提供的作品集参考图调整：纯白底、左侧项目标题与简介、右侧大幅模型画面、柔和虚化过渡，以及底部细线和项目编号。开场、滚动章节、交互展台与游戏图鉴使用统一的分栏排版。

同日按拆解效果参考继续更新：封面保留背景，其他模型区域、交互展台和图鉴容器均使用透明背景。新增“拆解与组合”章节，以及完整的展开、旋转、组合、变形演示。

“游戏表现”章节右侧现使用从游戏资源中提取的真实商城检视台场景 `assets/game-mall-scene.jpg`。场景来源于游戏实际加载的 `assets/ui/mall/hero3dbg~14811518.jpg`，武器使用项目中已提取的三维模型持续自转。左右箭头只切换检视武器，模型自动旋转；这里没有拆解、拖动或参数面板。前面的互动展台保持独立。

## 打开网站

Windows 上双击 **`启动网站.cmd`**。脚本会启动隐藏的本地服务并打开浏览器；重复启动会复用已经运行的本站服务。

也可以在本目录打开终端：

```powershell
npm start
```

浏览器访问 `http://127.0.0.1:8788/`。需要 Node.js；无需执行 `npm install`。

如需自选端口：

```powershell
node server.mjs 8790
```

网页用 ES Module 和 JSON 加载三维资源，请通过本地 HTTP 服务预览。直接双击 `index.html` 无法提供完整三维体验。

## 页面与操作

| 章节 | 展示内容 | 操作 |
| --- | --- | --- |
| 开场 | 左侧产品介绍、右侧实时三维模型与虚化映像 | 向下滚动或点击“向下探索” |
| 设计 | 蓝白材质、机身轮廓和细节 | 右侧模型随滚动转动 |
| 拆解与组合 | 枪管、装甲、上盖等部件的分离与归位 | 滚动展开、旋转、组合；回滚可逆向播放 |
| 形态 | S1 步枪至 S2 狙击的骨骼变形 | 向下推进、向上倒放 |
| 骨骼 | 18 根骨骼与层级连线 | 切换透视、完整材质、仅骨骼 |
| 交互展台 | 独立三维查看器 | 展开／组合、完整演示、拖动旋转、双击复位、变形、换弹、自转、切换视角模型 |
| 游戏表现 | 真实游戏商城检视台场景与多把武器轮换 | 左右箭头切换武器；模型自动旋转；场景只读 |

展台下方滑杆允许逐帧控制 S1 → S2 变形；播放按钮可暂停或继续。第一／第三人称按钮切换对应的武器网格，展示范围为武器本体。

第二条“拆解程度”滑杆控制部件分离距离。“展开”按钮会在展开后变为“组合”。“完整演示”约 12.4 秒，依次展示部件展开、旋转观察、重新组合、步枪变为狙击、再收拢为步枪；支持暂停／继续，也可再次点击“完整演示”停止。

部件按现有的 15 个有网格的骨骼分组进行刚性位移和小角度旋转，不会拉伸三角面。拆解是网页中设计的结构演示；变形与换弹仍使用原有动画数据。

手机布局将介绍放在上方、模型放在下方。网站尊重系统“减少动态效果”设置，此时滚动采用稳定视角与直接形态切换，主动点击的动画仍可播放。三维加载失败时保留原图和图文介绍。

拆解动效的专项验收保存在 `output/playwright/assembly-verification.json`，额外检查背景清除、部件实际位移、三角面边长保持、组合复原、完整演示、第一／第三人称以及手机端取景。修改前的作品集版保存在 `output/before-assembly-20261014/`。

只读游戏图鉴验收保存在 `output/playwright/game-display-verification.json`：包含原图片框的位置、自转、禁用交互、原图 UI 保留、移动端布局、减少动态效果和前一展台的独立性。修改前文件保存在 `output/before-game-display-20261014/`。

商城检视场景来自游戏启动器缓存中发现的资源 URL：`assets/ui/mall/hero3dbg~14811518.jpg`。同时在缓存资源索引中确认了商城模型背景相关的 `moxingbg`、`moxinghoubg` 和 `moxing1` 资源；本页面选择实际检视台场景图 `hero3dbg` 作为右侧底图。

`output/playwright/verify.cjs` 使用本机的 Playwright CLI 做复查。若 CLI 安装路径不同，将 `PLAYWRIGHT_CLI` 环境变量设置为本机 `playwright-cli.js` 的完整路径，并先打开名为 `freedom-wing` 的 CLI 浏览器会话。

## 2026-10-15 多武器检视完成记录

检视轮换包含：自由之翼、黄金圣龙、机械巨龙、惊龙、AK47·龙腾、龙腾·零式、M4A1·龙吟、巴雷特·祥龙、黑龙遗愿、魔龙·梦魇，共 10 把。

其他武器按各自 `weapon_config.json` 选择模型和材质，使用 `clips.idle.frames[0]` 的原始局部骨骼姿态。全局绑定矩阵与局部动画变换分别处理；魔龙·梦魇的 16 个混合权重顶点保留全部权重。贴图翻转方向和流光参数沿用各武器原预览器配置。检视使用项目原有粒子解析器及原始材质／贴图，复现模型和常驻枪身特效；页面不执行原游戏逻辑。

轮换共用一个 WebGL 画布，切换时释放旧网格，缓存已载入的资源。检视采用正交相机，按模型与真实粒子的完整水平旋转范围取景；手机端保留左右切换按钮。切换加载失败时保留上一把成功载入的武器和名称，可以再次点击切换。
